# Work Progress Dashboard

A local dashboard for tracking project and task progress.

Open `index.html` in a browser. Data is stored in that browser’s local storage.

## What you can do

- See overall completion, in-progress work, and blocked items
- Track progress per project
- Add, edit, and advance tasks
- Filter tasks by project, status, or search
- Export and import JSON backups

Sample projects and tasks load on first visit so the overview is not empty.
